# GitHub + Streamlit Community Cloud 部署指南

## 部署要求

- GitHub 入口：`streamlit_cloud_github/app.py`
- Python：3.11
- 数据源：SERENE `/api/download-output/`、`/api/download-forecast/` 和 Kp/ap
- 科学解释器：`breid-phys/aida-ionosphere` v0.1.3（MIT）

因为 Streamlit Cloud 不能给现有应用原地更换 Python，请先保存 URL 和
Secrets，删除旧应用，再创建应用并在 **Advanced settings** 选择 Python
3.11。

## Secrets

```toml
SERENE_API_BASE_URL = "https://spaceweather.bham.ac.uk"
# 请在 Streamlit Secrets 中另行添加 SERENE_API_TOKEN 及其私密值。
SERENE_API_TIMEOUT = "30"
SERENE_AUTH_SCHEME = "Token"
```

不要上传 `.env` 或 `.streamlit/secrets.toml`。聊天中曾公开的 token 必须撤销。

## 工作方式

一次 API 请求下载一个时间的 raw AIDA 状态文件。官方 AIDA 解释器在本地
计算所有经纬度点，因此地图点数和 API 请求次数相互独立。Kp/ap 是全球
指标，不进入区域地图。

ICAO-style 页面可读取分析时刻前3小时的37个五分钟状态和30个每日PSD
参考状态。主风险表、地图和研究消息只显示本次成功下载并解析的官方
+30分钟和+90分钟 forecast。+3小时和+6小时仍会作为可用性检查出现在
forecast audit，但不会成为主结果，也不会用0、OK或本地预测替代。
首次加载可能较慢；相同产品会由有界缓存复用。S4、
sigma-phi、PCA和SWF不属于当前SERENE AIDA输出，页面应移除这些不支持的
产品，而不是显示占位风险行、虚构的0或OK。

## 近实时运行与安全刷新

本项目是按需加载或可选定时刷新的 **near-real-time（近实时）** 学术研究原型，
不是零延迟的运行服务。Follow-latest 模式会先下载SERENE最新Ultra状态，读取
HDF5内部的真实AIDA周期，再用该精确时间请求forecast。手动模式仍使用用户选择
的历史时间。状态面板应显示请求时间、真实AIDA时间、数据年龄和刷新状态。

新会话默认开启 **Follow latest near-real-time**；关闭后才使用手动历史时间。
**Load / Refresh data** 始终可用。

**Auto-refresh every 15 minutes** 默认关闭，且只允许在 **Live SERENE API**、
**Quick Demo**、**Follow latest near-real-time** 三项同时满足时启用。调度刷新只在
安全的五分钟锚点改变时才重新加载。**Full ICAO-style mode** 必须手动加载，因为
单次可能请求37个滚动状态、最多30个基线状态和4个forecast可用性检查。

Forecast 请求必须以 analysis time 作为 `file_time`，以预测跨度作为 `period`；
页面显示的 valid time 由 `analysis time + period` 本地计算。这样避免当前日期
请求把未来时间传给 SERENE。即使 forecast 失败，成功的 observation 仍应保留。

2026-08-12使用有效token检查时，证明forecast是“按周期发布”的：较早的
Ultra和Rapid周期中，+30分钟、+90分钟返回HTTP 200 HDF5，+3小时、
+6小时返回HTTP 404；后续10:55 UTC的Ultra周期则四个跨度全部可用。
因此页面必须逐次检查，并区分：401/403鉴权失败、404未发布、网络失败和
HDF5解析失败。主决策界面仍有意限定为+30分钟和+90分钟。

2026-08-07 至 2026-08-10 的浏览器结果仅是修复前观察，不构成新部署已通过验证的
证据；新部署后必须执行 live acceptance test。2026-08-10 检查官方 Kp/ap CSV 时，
观察到最新时间戳为 `2026-07-07T03:00:00Z`。在官方96小时历史不足前，依赖 Kp/ap
的 PSD 与 HF COM 风险必须保持 unavailable，不能虚构实时 Kp、PSD 或 HF 值。HF
手动滑块只能标为假设 PSD 演示，不能声称为实时科学数据。

详细观察表和上线验收清单见
[`../docs/near_real_time_verification_2026-08-10.md`](../docs/near_real_time_verification_2026-08-10.md)。

## 常见问题

| 问题 | 处理 |
|---|---|
| 401/403 | 检查新 token 和 `Token` 认证方式 |
| 返回 non-HDF5 | 检查 base URL 必须是 `spaceweather.bham.ac.uk` |
| 导入 aida 失败 | 确认 Python 3.11，查看依赖安装日志 |
| 选定时间没有输出 | 换到已有归档时间；历史时间使用 final 产品 |
| Kp 没有区域色块 | 正确行为：Kp/ap 仅为全球背景指标 |
| PSD 显示 N/A | 选定时刻之前可能没有完整30天AIDA归档、部分参考状态不可用，或缺少完整96小时Kp历史 |
| +3h/+6h 不在主表 | 正确行为：它们仅保留在forecast audit中作为上游可用性证据 |

项目仅作学术演示，不是正式 ICAO 业务预警系统。
